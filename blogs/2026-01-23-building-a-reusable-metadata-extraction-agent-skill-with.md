Extracting metadata from documents is a common task. In Box, metadata like IDs, invoices, contracts, forms, and more often underpins search, automation, retention, and downstream workflows.But populating it at scale can be time-consuming. In this post, we’ll walk through a template-driven Agent Skill that reads files directly from a Box folder, extracts structured values using Box AI , and writes those values back as Box metadata — while keeping the files in Box as the system of record that continues to drive search, automation, and downstream workflows.
