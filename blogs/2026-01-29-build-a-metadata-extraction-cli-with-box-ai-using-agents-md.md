Build a metadata extraction CLI with Box AI — using agents.md as your spec Structured metadata is one of the most powerful layers in Box. It’s what powers search, filters, retention policies, automation, and downstream workflows. With Box AI, you can extract that structure directly from unstructured documents — invoices, contracts, forms — and apply it back to files in a repeatable way.
